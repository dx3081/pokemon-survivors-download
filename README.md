# 口袋妖怪幸存者

基于 PokéRogue 制作的宝可梦同人幸存者游戏，免费提供 **Windows 和 macOS 最终版**下载。

## 下载

前往 [最终版下载页](https://github.com/dx3081/pokemon-survivors-download/releases/latest)，选择对应系统的 ZIP 文件。

- **Windows**：下载 `PokemonSurvivors-Windows.zip`，完整解压后运行 `PokemonSurvivors.exe`。EXE 和 PCK 必须放在同一目录。
- **macOS**：下载 `PokemonSurvivors-macOS.zip`，解压后打开 `Pokemon Survivors.app`。

本仓库仅提供游戏成品下载。
